# ⚡ FlashForge

A spaced repetition flashcard app with achievement badges, deck management, and study streak tracking.

## ✨ Features
- **Spaced repetition** — Cards come back based on Again / Hard / Good / Easy ratings
- **Deck system** — Organize cards into named decks, filter study by deck
- **3D card flip** — Smooth CSS 3D animation on reveal
- **Bulk import** — Add multiple cards at once using `Front | Back` format
- **Achievement badges** — 8 unlockable badges (First Card, Week Warrior, Scholar...)
- **Session stats** — Reviewed, correct, struggled, accuracy tracked live
- **Mastery tracking** — Cards rated Easy ×3 are marked as mastered
- **Study streak** — Tracks consecutive study days
- **Hint system** — Add optional hints to each card

## 🛠 Tech Stack
- Pure HTML, CSS, JavaScript
- CSS 3D transforms for card flip
- Google Fonts: Syne, Inter

## 🎯 How to Use
1. Go to **Add Cards** tab → enter a deck name, front, back, and optional hint
2. Or use **Bulk Import** with `Front | Back` one per line
3. Go to **Study** tab → click a card to reveal the answer
4. Rate yourself: Again, Hard, Good, or Easy
5. Unlock **Achievements** as you study more

## 📊 Spaced Repetition Intervals
| Rating | Next Review |
|--------|-------------|
| Again | < 1 minute |
| Hard | 10 minutes |
| Good | 1 day |
| Easy | 4 days |
